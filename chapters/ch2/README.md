# Chapter 2: Programming a Guessing Game

See [`guessing_game/`](guessing_game/)

Key concepts:

- Bringing other libraries (`io`) into scope for usage
- Installing and using external dependencies/crates (`rand`)
- Using `loop` for repeated execution
- Using `match` for pattern matching and error handling
- Variable shadowing
- Using `break` and `continue` to control flow within loops
- Using `cmp` and `Ordering` to compare values
- Using `io` to read user input
- Using `let` to declare variables
- Using `println!` to print formatted output
